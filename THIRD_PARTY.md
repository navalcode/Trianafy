# Components and attribution

Original coursework packages, notes, authorship and Git history are retained. This review does not apply a new blanket project license or claim sole authorship of the existing implementation.

The existing Takari Maven Wrapper 0.5.6 keeps its notices and pinned Maven URL. Wrapper JAR bytes were compared with the official [Maven Central artifact](https://repo.maven.apache.org/maven2/io/takari/maven-wrapper/0.5.6/) before execution. This old wrapper does not enforce modern checksum properties; the comparison is an audit-time check. See [Maven Wrapper documentation](https://maven.apache.org/wrapper/).

Spring, Hibernate, H2, Lombok, JUnit, Mockito and existing OpenAPI dependencies retain their upstream notices/licenses through their declarations. No dependency upgrades, fonts, photos, generated screenshots or external datasets are added. New tests use fictional fixtures and no employer/client implementation or configuration. Existing music seeds and shared credits remain attributable to their original context.
